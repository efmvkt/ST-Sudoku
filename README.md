# ST-Sudoku — SillyTavern Extension

Полноценная игра в судоку прямо в SillyTavern. Оформление вдохновлено [sudoku.com](https://sudoku.com).

## Возможности

- 🟦 Три уровня сложности: Легко / Средне / Сложно
- ✏️ Режим заметок (карандашные цифры в ячейках)
- ↩ Отмена последнего хода
- ⌫ Стирание цифры
- ❌ Счётчик ошибок (3 ошибки — игра окончена)
- ⏱ Таймер
- ⌨️ Управление с клавиатуры (стрелки + цифры)
- 📱 Адаптивный дизайн для мобильных

## Установка через SillyTavern

1. Открой SillyTavern → Extensions → Install extension
2. Вставь URL репозитория:
   ```
   https://github.com/ВАШ_НИКНЕЙМ/ST-Sudoku
   ```
3. Нажми Install
4. Перезагрузи страницу

## Ручная установка (через SSH/VPS)

```bash
cd /путь/до/SillyTavern/data/default-user/extensions
git clone https://github.com/ВАШ_НИКНЕЙМ/ST-Sudoku
```

Перезагрузи SillyTavern.

| Действие | Клавиша |
